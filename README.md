# Integración de Sistemas · Progreso 1 (UDLA)

Material de estudio de las Semanas 1 a 3 y entregable del taller de la Semana 3.

## Contenido

| Carpeta | Qué es |
|---------|--------|
| `Integracion_Sistemas_P1/` | Sitio de estudio de 13 páginas. Abre `index.html` en el navegador. |
| `Semana3_API_REST/` | Entregable del taller: `openapi.yaml`, `README.md` y la colección de Postman. Incluye `extras_opcionales/` con un backend de ejemplo y una variante del contrato con seguridad. |

## Cómo usarlo

- **Sitio de estudio:** descarga el repositorio y abre `Integracion_Sistemas_P1/index.html`. No necesita instalación.
- **Taller:** importa `Semana3_API_REST/openapi.yaml` en Postman, o usa `postman/API.postman_collection.json`.
- **Backend opcional:**
  ```bash
  cd Semana3_API_REST/extras_opcionales/server
  npm install
  node server.js
  ```
